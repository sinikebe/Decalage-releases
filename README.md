# Décalage — téléchargements

Un jeu où tu fais bouger les lignes. Télécharge le jeu pour jouer sur Android
ou Windows ; aucun compte GitHub ni installation du code n'est nécessaire.

## Version de développement

La [page de téléchargement](https://github.com/sinikebe/Decalage-releases/releases/tag/branch-dev)
contient la version utilisée pour les essais de Décalage. Elle évolue avec les
retours de jeu et peut encore présenter des bugs.

- [Android : télécharger l'APK](https://github.com/sinikebe/Decalage-releases/releases/download/branch-dev/decalage.apk), puis ouvrir le fichier sur l'appareil pour l'installer.
- [Windows : télécharger le jeu](https://github.com/sinikebe/Decalage-releases/releases/download/branch-dev/Decalage.exe), puis ouvrir l'exécutable.

Les prochaines mises à jour de la version de développement apparaîtront sur
cette même page. Une version stable aura son propre canal lorsqu'elle sera publiée.

## Contenu de ce dépôt

Ce dépôt héberge les téléchargements et leurs informations de version.
Le téléchargement « Source code » proposé automatiquement par GitHub contient
uniquement les documents de ce dépôt de distribution ; utilise l'APK ou l'EXE
pour jouer.

Les fichiers `manifest.json` et `content-*.pck` servent aux mises à jour du jeu.
`SHA256SUMS` fournit les empreintes des téléchargements ; la licence du lanceur
est incluse dans `LAUNCHER-LICENSE.txt`.
